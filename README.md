# Connect 4 AI — عامل هوشمند بازی Connect 4

پروژه پایانی درس هوش مصنوعی — پیاده‌سازی عامل هوشمند بازی Connect 4 با الگوریتم **Minimax** مجهز به
**Alpha-Beta Pruning** و یک تابع ارزیابی هیوریستیک چندمعیاره.

## ساختار فایل‌ها

| فایل | توضیح |
|---|---|
| `game.py` | پیاده‌سازی محیط و قوانین بازی (صفحه، حرکات معتبر، تشخیص برد/تساوی) |
| `heuristic.py` | تابع ارزیابی هیوریستیک صفحه بازی |
| `minimax.py` | عامل هوشمند مبتنی بر Minimax و Alpha-Beta Pruning |
| `main.py` | اجرای بازی در محیط خط فرمان (کنسول) |
| `gui.py` | رابط گرافیکی بازی (بخش اختیاری/امتیازی) |
| `report.pdf` | گزارش فنی کامل پروژه |

## پیش‌نیازها

- Python نسخه ۳.۸ یا بالاتر
- برای اجرای نسخه گرافیکی (`gui.py`)، کتابخانه **Tkinter** لازم است که معمولاً به‌صورت پیش‌فرض همراه
  پایتون نصب می‌شود. در صورت نبودن آن روی لینوکس:

```bash
sudo apt-get install python3-tk
```

هیچ کتابخانه یا وابستگی خارجی دیگری (مانند numpy یا pygame) مورد نیاز نیست؛ پروژه فقط با کتابخانه‌های
استاندارد پایتون کار می‌کند.

## نحوه اجرا

### ۱) نسخه کنسولی (خط فرمان)

```bash
python3 main.py
```

پس از اجرا، صفحه بازی در ترمینال نمایش داده می‌شود. برای انجام حرکت، شماره ستون موردنظر (بین ۰ تا ۶) را
وارد کرده و کلید Enter را بزنید. پس از هر حرکت AI، تعداد گره‌های بررسی‌شده توسط الگوریتم Alpha-Beta نیز
در ترمینال چاپ می‌شود.

### ۲) نسخه گرافیکی (GUI)

```bash
python3 gui.py
```

در این نسخه می‌توانید:
- با کلیک روی هر ستون از صفحه، مهره خود را (قرمز) قرار دهید.
- از پنل کناری، سطح دشواری عامل هوشمند (زرد) را انتخاب کنید:
  - **Easy** → عمق جستجو ۳
  - **Medium** → عمق جستجو ۵ (پیش‌فرض)
  - **Hard** → عمق جستجو ۷
- با دکمه **NEW GAME** بازی را از نو شروع کنید.

## نحوه کارکرد عامل هوشمند (خلاصه)

عامل هوشمند در فایل `minimax.py` پیاده‌سازی شده و پیش از هر حرکت به این ترتیب تصمیم می‌گیرد:

1. اگر یک حرکت برای برد فوری وجود داشته باشد، همان انتخاب می‌شود.
2. اگر بازیکن انسانی در نوبت بعدی بتواند فوراً برنده شود، آن ستون مسدود می‌شود.
3. در غیر این صورت، جستجوی **Minimax + Alpha-Beta Pruning** تا عمق تنظیم‌شده اجرا شده و بهترین حرکت بر
   اساس تابع ارزیابی هیوریستیک (`heuristic.py`) انتخاب می‌شود.

جزئیات کامل مدل‌سازی فضای حالت، الگوریتم و تابع هیوریستیک در فایل `report.pdf` توضیح داده شده است.

## نکته درباره عمق جستجو

افزایش عمق جستجو (به‌ویژه در حالت Hard) دقت تصمیم‌گیری عامل را بالا می‌برد اما زمان پاسخ‌دهی را نیز افزایش
می‌دهد. در صورت کند بودن اجرا روی سیستم شما، پیشنهاد می‌شود از سطح دشواری Medium یا Easy استفاده کنید.
